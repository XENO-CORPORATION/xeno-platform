# Landing asset replacements

## Scope

Eight previously unresolved landing PNG paths now contain five newly generated
original illustrations. Built-in ImageGen was used with text-only prompts, no
reference images. Four legacy v2 hero aliases intentionally share one new hero;
the four v3 gallery slots each have a different new illustration.

Exact prompts, output filenames, inspection notes and SHA-256 hashes are retained
in `compliance/generated-assets-2026-09-05.json`. All eight paths are registered in
`compliance/assets.json` with the existing documented provider terms basis. These
are decorative illustrations, not real product screenshots, customer work or
results generated by a XENO model. This does not establish exclusive copyright.

Original bytes remain recoverable in Git at commit
`9b90df43f2392d450495c32217e6786d0699ec62` and in this checkout's
`.compliance/asset-originals-20260905/public/` backup. No originals were deleted
from history or from the separately running localhost checkout.

## Remaining work

The prior 31-path inventory is a historical snapshot. Eight paths are addressed
by replacements here; 23 still require work: nine identity/icon files and fourteen
other media files. No owner declaration, trademark permission, licensing exception
or signed determination is made by this change. Existing XENO logos, the Flux mark,
the video, map and legacy demo have not been cleared by regenerating artwork.

The focused provenance tests pass. Full release qualification must bind to the
updated tree and rebuilt artifact; the preceding BLOCK gate cannot become PASS
merely because these eight files changed. Other package-license and contributor
findings remain outside this asset replacement change.
