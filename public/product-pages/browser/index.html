This browser

The local agent perceives and acts on the live page in this window: navigate, click, type, read and attach files.

Run in cloud

Dispatches the task to the hosted agent-runs service instead.

Scoped consent

Bounded mount points, no path traversal, and confirmation for high-risk file operations.

Drivable from outside

xeno-agent-cli in a terminal, the agent SDK in any app, or XENO Hub can drive it.
