Double-click anything.
It just opens.

One Windows app for your images, video, audio and 3D models, instead of a different viewer for each. Arrow keys walk the folder. When you want to change the file, it goes straight to the XENO app built for it.

One window for all of it

Four kinds of file, the tools each one needs.

View registers with File Explorer when it installs, so these files can open in it directly. The same window, the same keys, whatever you double-clicked.

ImagesPNG JPG WEBP GIF SVG BMP ICO AVIFPan and zoom, fit or actual pixels, rotate. The Details panel shows dimensions, format, size and a live RGB histogram.
VideoMP4 WEBM MOV MKV AVIScrub, change speed from 0.5x to 2x, and step one frame at a time. Plays the codecs the built-in engine decodes.
AudioMP3 WAV OGG FLAC M4A AACPlay it with an animated frequency view, a timeline and volume.
3D modelsGLB GLTF OBJ STLOrbit, pan and spin it. Shaded, wireframe, normals or unlit, with a ground grid and live polygon counts.
Walk the folderThe left and right arrow keys go through every viewable file beside the one you opened, in the order you would expect: img1, img2, img10. The filmstrip shows where you are.
Open it where it can be changedOne click sends the file to XENO Pixel, Motion, Sound or Form when that app is installed. Copy the image or its path, or show it in its folder.
AI RestyleAsk for a new look and get it as a new version beside the original. Your file is untouched until you save a copy or replace it. Runs on your XENO account and uses credits.
