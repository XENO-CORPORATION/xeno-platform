Generation is a job

Video takes minutes, so it’s built like it.

The contract is submit, then poll, then settled, with optional cancel and progress. A surface that can only fire and wait resolves submit when the job finishes and treats poll as a no-op.

01submitSend the prompt and settings
02pollAsk how far along it is
03cancelOptional: stop a running job
04settledThe clip, or a clear error

The product never sees provider credentials. It can’t reach Replicate, fal.ai or Gemini and doesn’t know they exist: it asks the host which models it can run and renders that list.
