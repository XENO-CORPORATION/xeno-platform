Non-destructive by design

Start with a cube

Eight vertices. Everything after this is a modifier, so the cube is never touched again.

Subdivide it

Two levels of subdivision round it into a soft form. Turn it off and the cube is still there.

Twist it

A deformer rotates each ring a little more than the last. Change the angle at any time.

Mirror it

Model one side; the other follows. Edits to the original mirror across instantly.

Array it

One lamp becomes a row of them. Change the count and the row rebuilds.
