Connect · model · embed

One dashboard engine for everything XENO makes.

Planned sources include databases, files, APIs and XENO’s own data. Metrics are defined once in a semantic layer, and every dashboard can be embedded in Hub, Shell, Post and external sites.

Semantic layer

Named metrics, dimensions and relationships, reused by every chart and every agent query.

Plain-language questions

Turned into governed semantic queries, never raw SQL against production. Runs locally on xeno-rt or in the cloud.

Agents as analysts

An agent can connect a source, define a metric, build a dashboard and watch an alert through the same tools.

Chart engine

Line, bar, area, scatter, heatmap, funnel, sankey, geo, stat tiles and tables, with drill-down and cross-highlighting.
