Local inference runtime

Models on your machine.
No wrapper underneath.

Evidence-gated

A model is supported when the evidence says so.

Parsing a file or passing a smoke test doesn’t count. Each model, backend and quantisation needs evidence for correctness, quality, memory, performance, API and reliability before it is listed.
