Built for daily use

Not a mode inside Hub. The desktop itself.

Hub becomes the default app inside Shell. Every XENO app runs inside it through one contract, window.xenoShell.

Real terminals

Fabric terminals run on a real PTY: your local shell, or ssh:// to another machine, in as many windows as you like.

Scoped folders

Apps get opaque handles to folders you mount, with a consent prompt and an audit log.

Every display

Per-display fullscreen, multi-monitor, autostart and session restore.

Fast to start

Boots in about 661 ms at the median, measured on the built beta.

Signed updates

An installer with a signing gate, staged auto-update and a crash spool.

Tested

195 of 195 tests and 3 end-to-end suites passing against the packaged build.
