v0.1.0 March 2026

Initial Release

The first public release of XENO Workflow brings a complete visual workflow automation environment with AI-native pipelines.

Core Features

  • + Visual node editor with React Flow canvas
  • + 12 node categories: Triggers, XENO apps, AI, Data, External, Logic
  • + Rust execution engine with durable execution and checkpointing
  • + Time-travel debugging with step-through and replay
  • + Error handling: break, resume, retry, rollback
  • + Parallel branch execution with merge strategies
  • + Workflow templates and marketplace
  • + Keyboard shortcuts and command palette

AI Features

  • + 22+ local AI models via XENO Lib
  • + Agent nodes with memory and context
  • + RAG and MCP integration
  • + Built-in prompt IDE for tuning AI nodes
  • + All AI models run locally via XENO Lib

Integration

  • + Native nodes for Pixel, Motion, Sound, 3D, Architect, Engine
  • + Integration SDK: TypeScript, Python, Rust
  • + Real-time collaborative sync
