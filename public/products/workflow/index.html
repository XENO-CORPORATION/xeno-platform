Features

Visual Node Editor

React Flow-based canvas for building workflows visually. Drag-and-drop nodes, connect data flows, and see results in real time.

12 Node Categories

Triggers, XENO app nodes (Pixel, Motion, Sound, 3D, Architect, Engine), AI nodes, data transforms, external services, and logic gates.

Durable Execution

Rust-powered execution engine via napi-rs with checkpointing, parallel branches, and automatic retry. 20ms overhead per node.

Time-Travel Debugging

Step through workflow executions, inspect data at every node, and replay from any checkpoint. Full execution history with diff view.

AI-Native Pipelines

22+ local AI models via XENO Lib. Agent nodes with memory, RAG, MCP integration, and a built-in prompt IDE for tuning.

Error Handling

Break, resume, retry, and rollback at any point. Error workflows, dead letter queues, and automatic alerting for failed executions.

Integration SDK

Build custom nodes in TypeScript, Python, or Rust. Publish to the node marketplace or keep them private to your team.

Real-Time Collaboration

Edit workflows simultaneously with your team through live collaborative sync. Git-backed versioning with branch, merge, and conflict resolution.

XENO App Integration

Native nodes for every XENO app. Batch-process images in Pixel, render videos in Motion, master audio in Sound — all automated.
