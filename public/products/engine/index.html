Features

ECS Architecture

Entity-Component-System architecture for high-performance game logic. Data-oriented design with cache-friendly memory layout and parallel processing.

Real-Time PBR Rendering

Physically-based rendering with global illumination, screen-space reflections, volumetric lighting, and post-processing. GPU-driven pipeline.

Physics Engine

Integrated rigid body and soft body physics. Collision detection, raycasting, joints, constraints, and character controllers.

TypeScript Scripting

Write game logic in TypeScript with hot-reload. Full API access to engine systems, scene graph, input, audio, and networking.

Visual Scripting

Node-based visual scripting for designers and artists. Create game logic, animations, and interactions without writing code.

Multiplayer

Built-in networking with client-server architecture. State synchronization, RPCs, lobby management, and matchmaking integration.

Cross-Platform Export

Export to Windows, macOS, Linux, and Web (WebAssembly). Single codebase with platform-specific optimizations.

AI Game Tools

AI-powered level generation, NPC behavior, dialogue, and asset creation. Generate game content from text descriptions using local models.

Asset Pipeline

Import FBX, glTF, OBJ, PNG, HDR, WAV, and more. Automatic LOD generation, texture compression, and asset bundling.
