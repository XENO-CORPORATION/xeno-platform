Release Notes

v0.2.0 March 2026 Latest

First Public Alpha

The first public release of XENO 3D brings a complete 3D creation environment with modeling, animation, rendering, and AI-powered procedural generation.

Core Features

  • + Polygon modeling with full mesh editing tools
  • + Digital sculpting with dynamic topology
  • + UV mapping with automatic unwrapping
  • + PBR material system with node-based shader editor
  • + Keyframe animation with skeletal rigging
  • + GPU-accelerated path tracing renderer
  • + Customizable workspace with dockable panels
  • + Keyboard shortcuts and command palette

AI Features

  • + Procedural 3D model generation from text prompts
  • + AI PBR texture generation
  • + AI-assisted retopology
  • + Agent sidebar for natural language control
  • + All AI models run locally via XENO Lib

Format Support

  • + Import: FBX, OBJ, glTF, USDZ, Alembic, 3DS, DAE, STL, PLY
  • + Export: FBX, OBJ, glTF, USDZ, Alembic, STL
  • + Native .xeno project format
