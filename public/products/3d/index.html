Features

Polygon Modeling

Full mesh editing with extrude, bevel, loop cut, bridge, and boolean operations. Non-destructive modifier stack for procedural workflows.

Sculpting

High-resolution digital sculpting with dynamic topology, multires, and pressure-sensitive brushes. GPU-accelerated for millions of polygons.

UV Mapping

Automatic UV unwrapping with manual editing tools. Smart projection, seam-based unwrap, and real-time UV preview on the 3D viewport.

PBR Materials

Physically-based rendering materials with node-based shader editor. Metallic/roughness workflow with real-time viewport preview.

Animation

Keyframe animation with curves, dope sheet, and graph editor. Skeletal rigging, IK/FK, and blend shapes for character animation.

Path Tracing

GPU-accelerated path tracer for photorealistic rendering. Global illumination, caustics, volumetrics, and adaptive sampling.

Procedural Generation

AI-powered procedural mesh generation from text prompts. Generate 3D models, textures, and materials using local AI models.

AI Texturing

Generate PBR texture sets from text descriptions. AI-powered texture painting directly on 3D surfaces with local models.

Format Support

FBX, OBJ, glTF, USDZ, Alembic, 3DS, DAE, STL, PLY, and XENO's native format. Import and export with full material preservation.
