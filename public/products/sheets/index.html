Features

Formula Engine

400+ Excel-compatible functions powered by HyperFormula. SUM, VLOOKUP, INDEX/MATCH, array formulas, and custom functions.

Virtual Grid

Canvas-based renderer handles millions of rows and columns at 60fps. Instant scrolling and rendering with O(1) complexity.

Charts

Bar, line, pie, scatter, area, and combo charts. Interactive visualizations with customizable styles and data ranges.

Pivot Tables

Drag-and-drop pivot table builder. Summarize, group, and analyze large datasets with automatic aggregations.

AI Data Analysis

Ask questions about your data in natural language. AI generates formulas, creates charts, and identifies patterns.

Conditional Formatting

Color scales, data bars, icon sets, and custom rules. Visual indicators that highlight trends and outliers.

XLSX Compatibility

Import and export Excel files with full formula and formatting preservation. Seamless interchange with existing workflows.

Collaboration

Real-time multi-user editing with CRDT-based sync. Cell-level conflict resolution and shared workbooks.

Data Validation

Dropdown lists, number ranges, date constraints, and custom rules. Prevent invalid data entry at the cell level.
