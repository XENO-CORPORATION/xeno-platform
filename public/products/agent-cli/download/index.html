Install XENO Agent CLI

v0.4.43 · Windows, macOS, Linux · Node.js 18+

Install via npm

npm install -g @xeno-corporation/xeno-agent-cli@0.4.43

Build from source

git clone https://github.com/XENO-CORPORATION/xeno-agent-cli
cd xeno-agent-cli
npm install && npm run build
npm link

Quick Start

# Check the installed version
xeno -V

# Start the interactive agent
xeno

# One-shot mode
xeno run "Create a React component for user profiles"
