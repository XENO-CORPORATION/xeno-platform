Features

Layer System

Full compositing with blend modes, opacity, groups, masks, and non-destructive editing. Unlimited layers with real-time preview.

Brush Engine

Pressure-sensitive brushes with customizable dynamics, texture, and flow. GPU-accelerated for smooth, responsive strokes.

AI Generation

Generate images from text prompts directly on canvas. Inpaint, outpaint, and transform selections with local AI models.

Selection Tools

Marquee, lasso, magic wand, and AI-powered subject selection. Refine edges with precision masking controls.

Filters & Effects

Blur, sharpen, color adjustments, distortions, and artistic filters. Non-destructive with real-time preview.

Vector Tools

Pen tool, shapes, text, and path operations. Mix raster and vector on the same canvas with auto-rasterization.

AI Upscaling

Upscale images 2-4x with ESRGAN models running locally. Preserve details and enhance textures automatically.

Background Removal

One-click AI background removal using local segmentation models. Clean cutouts with edge refinement.

Format Support

PSD, PNG, JPEG, WebP, SVG, TIFF, and XENO's native format. Import and export with full layer preservation.
