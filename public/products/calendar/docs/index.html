Learn how to set up and use XENO Calendar for scheduling and time management.

Getting Started

  • Adding a calendar — Go to Settings and click Add Calendar. Connect via CalDAV URL or sign in with Google/iCloud.
  • Creating events — Click any time slot or use the + button. Set title, time, recurrence, and reminders.
  • AI scheduling — Click the AI button when creating an event to get smart time suggestions based on your availability.
