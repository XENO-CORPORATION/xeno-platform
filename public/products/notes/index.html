Features

Markdown Editor

Write in Markdown with live WYSIWYG preview. Code blocks, math (LaTeX), diagrams, and embeds all rendered inline.

Bi-Directional Links

Link notes with [[wikilinks]]. See all backlinks and unlinked mentions. Build a connected knowledge graph naturally.

Graph View

Visualize your knowledge as a force-directed graph. Explore connections, clusters, and orphan notes at a glance.

Daily Notes

Automatic daily notes for journaling, meeting notes, and task tracking. Templates for consistent daily workflows.

AI Search & Q&A

Semantic search across all notes. Ask questions and get answers from your knowledge base using local AI models.

Canvas Mode

Whiteboard for visual note-taking. Arrange cards, draw connections, embed notes, and brainstorm spatially.

Tags & Notebooks

Hierarchical notebooks and nested tags. Multiple organization strategies that work together seamlessly.

Local-First Storage

All notes stored as plain Markdown files on disk. Your data is yours — no cloud required, fully portable.

Full-Text Search

Instant fuzzy search across all notes, titles, tags, and content. Find anything in milliseconds.
