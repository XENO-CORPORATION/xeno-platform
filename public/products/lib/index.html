Technical Details

Rust Core

Written in Rust for maximum performance and memory safety. Zero-copy data pipelines between models.

ONNX Runtime

Standardized model format with optimized inference. DirectML, CUDA, and CPU execution providers.

GPU Acceleration

CUDA and SIMD acceleration for NVIDIA GPUs. Automatic fallback to CPU when GPU is unavailable.

Output Formats

  • Images: RGBA u8 buffers (width x height x 4 channels)
  • Audio: f32 PCM samples (mono/stereo, variable sample rates)
  • Masks: Single-channel u8 buffers (0-255 opacity)
  • Depth maps: f32 depth buffers (normalized 0.0-1.0)
  • Embeddings: f32 vectors (variable dimensions)
  • Metadata: JSON (bounding boxes, landmarks, labels, scores)
