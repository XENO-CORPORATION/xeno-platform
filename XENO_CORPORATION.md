## Products

### XenoCode
**Domain:** xenocode.ai
**Type:** CLI Coding Assistant
**Status:** In Development

AI-powered terminal coding assistant for developers. Like having a senior engineer in your terminal.

**Features:**
- Agentic coding with file operations, bash execution, and code editing
- Session persistence and resume
- Checkpoint system with rewind capability
- Multi-model support (Claude, Gemini, local models)
- Custom commands and skills system
- Trust prompts for security

**Subdomains:**
- `cli.xenocode.ai` - CLI tool downloads & docs
- `ide.xenocode.ai` - IDE extension (VS Code, JetBrains)
- `docs.xenocode.ai` - Documentation
- `api.xenocode.ai` - API access

**Target Users:** Software developers, DevOps engineers, technical teams

## Technology Stack

### Core Technologies
- **Runtime:** Bun, Node.js

- **Proxy:** Antigravity Claude Proxy (development)

- **API:** REST, WebSocket for real-time

- Computer Vision (screen understanding)
- Code Generation and Analysis
- Multi-modal Understanding

- **Style:** Clean, minimal, futuristic
- **Typography:** Monospace for code, Sans-serif for UI

- Products: "Xeno" + function (XenoCode, XenoAgent)
- Hyphenated for .com: xeno-gen.com, xeno-chat.com
